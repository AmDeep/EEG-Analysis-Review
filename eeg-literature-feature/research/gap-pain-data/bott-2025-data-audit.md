# Bott et al. 2025 pooled chronic pain EEG data status

Primary paper: https://pmc.ncbi.nlm.nih.gov/articles/PMC12517086/ (DOI 10.1016/j.ebiom.2025.105955). Its methods say it analyzed eight independent resting EEG datasets (n=614), acquired two local sets and obtained six external datasets via outreach to research groups; the article explicitly describes secondary analyses of de-identified data from “controlled-access repositories.” Its structured campaign found only four external groups contributed; some did not respond, no longer had access, or wanted further analyses before sharing. Therefore the entire pooled participant-level 8-set corpus is not verified as publicly downloadable and should not be labeled public.

A potentially matching OSF component is public: https://api.osf.io/v2/nodes/m45j2/ identifies “Chronic pain EEG dataset,” described as resting EEG from chronic-pain patients using mobile dry-electrode EEG; its public BIDS folder exposes sub-001_task-EC_eeg.vhdr (4,146 bytes), sub-001_task-EC_eeg.vmrk (478 bytes), and the actual raw voltage recording sub-001_task-EC_eeg.eeg (17,832,448 bytes), alongside JSON/channels/events metadata; the OSF API listing returns these names and sizes. This resembles a Munich CGX dry-electrode cohort described in Bott methods, but the inspected evidence does not explicitly map node m45j2 to one of Bott's eight set labels or demonstrate that all cohorts/all processed participant data are public. Record as one publicly accessible raw pain-EEG project/component, not public access to the pooled Bott dataset.
