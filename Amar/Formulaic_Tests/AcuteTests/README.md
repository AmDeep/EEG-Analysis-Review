# EEG Pain Scale Complete Validation Package

## Open these first
- `FINAL_VALIDATION_RESULTS.docx` and `FINAL_VALIDATION_RESULTS.md`: authoritative current report. Distinguishes aggregate-level formula tests from uncompleted individual-level validation.
- `aggregate_formula_results/`: actual outputs generated by running `aggregate_formula_validation.py` on published acute-pain EEG group means.
- `acute_trial_validation_pipeline.py`: reproducible pipeline for real trial-level EEG-derived feature data with ratings, when it is available locally.
- `aggregate_formula_validation.py`: the calculation script for the aggregate tests.
- `formula_test_coverage.csv`: lists which formula families could be tested and why others could not be tested from aggregate values.
- `data_access_audit.txt`: describes attempts to retrieve actual data and the reason raw records were not loaded.
- `EEG_Pain_Scale_Workbook.xlsx`: earlier project workbook retained from previous outputs. It has not been updated with the newest aggregate-level rows; the newest numeric results are in CSV/JSON under `aggregate_formula_results/`.

## Main result
Actual published EEG group-average N2/P2 peak values were used to fit three simple linear formulas against assigned NRS band midpoints (5, 7, 9). P2-only had leave-one-band-out MAE 0.0386, N2-P2 MAE 0.0492, absolute N2 MAE 0.0606; all three had monotonic rank rho=1 but exact rank-permutation p=0.333 with only three points. The transferred external power law was badly under-calibrated (MAE 3.807). These aggregate calculations are **not** validation on individual trials or patients.

## Trial-level data contract
`acute_trial_validation_pipeline.py` needs a local genuine CSV with `subject_id`, `trial_id`, `pain_nrs`, numeric EEG feature columns (for example `n2_uv`, `p2_uv`, `z_alpha`, `z_beta`), and optionally `trial_order`. Do not place one row per group mean into this pipeline. A row must correspond to a real trial with EEG-derived features matched to its actual pain rating.

## Important limitations
The network-enabled web interface could inspect source pages, but the local processing environment could not resolve GitHub raw-content hostnames (DNS error). No raw EEG binaries or paired trial-level feature matrix were downloaded. No trial-level model metrics, per-subject pain scores, participant-grouped CV, cluster-bootstrap confidence intervals, or permutation tests were invented. The included aggregate results are valid calculations but insufficient for clinical claims.

## Additional source access note
`SOURCE_DATA_ACCESS_UPDATE.md` documents a source-visible trial-rating CSV (416 rows) and why it still cannot be used to score trials: it contains labels and stimulus levels but no EEG predictors. A CSV inventory is provided in `trial_rating_table_source_inventory.csv`. The data-access audit was updated to reflect this inspection.
